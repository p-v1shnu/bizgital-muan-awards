# ຂໍ້ຄວາມພາສາລາວທີ່ຕ້ອງໃຫ້ຄົນລາວກວດ

> ทุกบรรทัดในไฟล์นี้ **AI เป็นคนเขียน ยังไม่มีเจ้าของภาษาตรวจ**
> เรียงจากอันที่คนนอกเห็น (แก้ก่อน) ไปหาอันที่เฉพาะทีมงานเห็น
>
> **ข้อความบนเส้นทาง error ทั้งหมดเป็นภาษาอังกฤษแล้ว** (ดูข้อ 1) —
> เหลือที่ต้องตรวจคือข้อความตอนใช้งานปกติเท่านั้น

---

## 1. ~~คนทั่วไปเห็นตอนระบบมีปัญหา~~ — **เปลี่ยนเป็นภาษาอังกฤษหมดแล้ว**

เจ้าของโปรเจกต์ตัดสินใจว่า **ทุกข้อความบนเส้นทาง error เป็นภาษาอังกฤษ** รวมถึงที่คนทั่วไปเห็นด้วย

เหตุผล: ข้อความ error คือข้อความชนิดเดียวที่**ถูกออกแบบมาให้ไม่มีใครเห็นตอนใช้งานปกติ** —
ทีมใช้ระบบเป็นปีก็ไม่เจอ จึงไม่มีทางถูกตรวจภาษาเลย · ภาษาอังกฤษที่อ่านรู้เรื่อง
ดีกว่าภาษาลาวที่ไม่มีใครยืนยันได้ว่าถูก

หน้าที่เป็นภาษาอังกฤษแล้ว: หน้า 404 · หน้า error ของเว็บ · หน้าตอนเซิร์ฟเวอร์ล่ม
(`error-pages/outage.html`) · ข้อความตอนส่งชื่อถี่เกินไป · ข้อความตอนส่งฟอร์มไม่สำเร็จ
· ข้อความปฏิเสธตอนประกาศ · ข้อความอัปโหลดรูปไม่สำเร็จ

**รวมถึงปุ่มบนหน้า error และชื่อแท็บตอน error ด้วย** — เจ้าของโปรเจกต์อนุญาตเฉพาะ
สองอย่างนี้ เพราะปุ่มพวกนี้ (`Reload` · `Home` · `Latest year` · `Hall of winners`
· `Try again`) มีไว้ให้ **ออกจากหน้าที่พังเท่านั้น** ไม่ใช่ปุ่มของระบบจริง ·
ชื่อแท็บตอน error คือ `Page not found`

> **ปุ่มและ UI ส่วนอื่นของระบบยังเป็นภาษาลาวทั้งหมด** และต้องเป็นแบบนั้นต่อไป —
> ภาษาลาวปนอังกฤษตรงนี้ไม่ใช่ปัญหา ห้ามแปลงปุ่มในตารางข้อ 2 และข้อ 3 เป็นอังกฤษ

**ไม่ต้องตรวจอะไรในหัวข้อนี้แล้ว**

## 2. คนทั่วไปเห็นตอน **ใช้งานปกติ** — ทีมจะเห็นเองตอนเปิดเว็บ

| ที่ | ข้อความ |
|---|---|
| หน้าปี ตอนเปิดรับ | ປິດຮັບ {วันเวลา} |
| หน้าปี ตอนปิดรับแล้ว | ປິດຮັບລາຍຊື່ແລ້ວ — ຢູ່ລະຫວ່າງການຄັດກອງ ແລະ ຕັດສິນ |
| การ์ดหน้าแรก ตอนเปิดรับ | ເປີດຮັບເສີນຊື່ແລ້ວ · ສົ່ງຊື່ຜູ້ສ້າງສັນທີ່ທ່ານຄິດວ່າສົມຄວນໄດ້ຮັບລາງວັນ |
| `/submit` ตอนปิดแล้ว | ປິດຮັບແລ້ວ · ການເສີນຊື່ຂອງງານປີ {ปี} ປິດແລ້ວ ເມື່ອ {วันที่} · ຕອນນີ້ຢູ່ລະຫວ່າງການຄັດກອງ ແລະ ຕັດສິນ |
| `/submit` ตอนยังไม่เคยเปิด | ຍັງບໍ່ເປີດຮັບ · ຕອນນີ້ຍັງບໍ່ໄດ້ເປີດຮັບການເສີນຊື່ … |
| ช่องกรองสาขา ตอนหาไม่เจอ | ບໍ່ພົບສາຂາທີ່ກົງກັບ “…” |
| คำบรรยายรูป (alt) — คลังภาพหน้าแรก | ບັນຍາກາດງານ ມ່ວນ ອະວອດ |
| คำบรรยายรูป (alt) — คลังภาพหน้าปี | ບັນຍາກາດ {ชื่องานปีนั้น} |
| คำบรรยายรูป (alt) — hero หน้าแรกตอนยังไม่กรอกคำบรรยาย | ງານມອບລາງວັນ ມ່ວນ ອະວອດ |

> **สามบรรทัดล่างเป็น `alt` ของรูป** — คนทั่วไปไม่เห็นบนจอ แต่ Google Images
> กับ AI อ่าน และ screen reader อ่านออกเสียง · ที่เหลือ (รูปคน รูปปีนั้นๆ)
> ใช้ชื่อคนหรือชื่องานที่ทีมกรอกเองอยู่แล้ว ไม่ได้เขียนขึ้นใหม่

## 3. เฉพาะทีมงานเห็น — ตรวจทีหลังได้

| ที่ | ข้อความ |
|---|---|
| เช็กลิสต์ก่อนเผยแพร่ | ຕັ້ງສາຂາເດັ່ນ 3–6 ສາຂາ · ມີວັນທີຈັດງານ ແລະ ສະຖານທີ່ · ມີຮູບ key visual ຂອງປີ · ມີຄະນະກຳມະການຢ່າງໜ້ອຍ 1 ທ່ານ |
| ปุ่มถูกล็อก | ຕ້ອງແກ້ {n} ຢ່າງທີ່ໝາຍສີແດງກ່ອນ — ໃສ່ນອມິນີ ຫຼື ລຶບສາຂາທີ່ວ່າງອອກ |
| ปุ่มไปต่อได้แต่ยังขาด | ຍັງຂາດ {n} ຢ່າງຂ້າງເທິງ — ໄປຕໍ່ໄດ້ ແຕ່ໜ້າປີຈະຍັງບໍ່ຄົບ |
| กล่องรวมกลุ่ม | ລວມ “{ชื่อ}” ກັບກຸ່ມໃດ? · ຊື່ຂອງກຸ່ມປາຍທາງຈະເປັນຊື່ທີ່ໃຊ້ຮ່ວມກັນ · ທັງ {n} ລາຍການຈະຍ້າຍໄປຢູ່ກຸ່ມນັ້ນ · ຊື່ທີ່ຜູ້ສົ່ງພິມມາຈະຖືກເກັບໄວ້ຢູ່ ບໍ່ໄດ້ຫາຍໄປ |
| ในรายการที่ถูกรวม | ສົ່ງມາເປັນ “{ชื่อเดิม}” |
| ปุ่มในคิว | ລວມກັບກຸ່ມອື່ນ |
| ไม่มีกลุ่มให้รวม | ສາຂານີ້ຍັງບໍ່ມີກຸ່ມອື່ນທີ່ລໍຖ້າຄັດກອງ |

## วิธีแก้เมื่อเจอที่ผิด
