# ตรวจไวยากรณ์ภาษาลาวทั้งเว็บ — วิธีทำงานร่วมกัน

## ทำไมถึงเป็นแบบนี้

ข้อความภาษาลาวในโปรเจกต์นี้ **AI เขียนทั้งหมด ยังไม่มีเจ้าของภาษาตรวจสักบรรทัด** ·
นับได้ **809 ข้อความที่ไม่ซ้ำกัน** กระจายอยู่ใน 54 ไฟล์

ด้วยจำนวนขนาดนี้ วิธี "ไปไล่หาเองแล้วค่อยมาบอกทีละคำ" จะพลาดแน่ —
เพราะข้อความส่วนใหญ่โผล่เฉพาะบางสถานะเท่านั้น (ปีที่ยังไม่เผยแพร่ · ตอนยังไม่เปิดรับ ·
ตอนไม่มีข้อมูล · กล่องยืนยันตอนลบ) เปิดเว็บดูเฉย ๆ จะไม่มีวันเห็นครบ

**ผมจึงดึงออกมาให้ครบทุกจุดแล้ว** เหลือแค่ให้คุณเติมคำที่ถูก

## วิธีกรอก

ทุกไฟล์เป็นตารางเดียวกัน:

| ID | ข้อความตอนนี้ | บรรทัด | แก้เป็น |
|---|---|---|---|
| P-014 | ຜູ້ຊະນະປີ {…} | 208 |  |

- เติมภาษาลาวที่ถูกต้องลงช่อง **แก้เป็น**
- ถูกอยู่แล้ว → ใส่ `OK`
- ไม่แน่ใจ → ใส่ `?` แล้วเขียนหมายเหตุต่อได้
- `{…}` คือช่องที่ระบบเติมค่าเอง (ปี · ชื่อ · จำนวน) — เขียนคำรอบ ๆ ได้ตามปกติ แค่อย่าลบ `{…}` ทิ้ง
- `→` `←` `↑` `↓` `·` `—` เป็นสัญลักษณ์ตกแต่ง ไม่ต้องแปล
- ประโยคยาวที่ถูกตัดเป็นหลายบรรทัดใน UI จะมาเป็นหลายแถวติดกัน (บรรทัดใกล้กัน) — อ่านรวมกันได้เลย
- ทุกแถวมีรหัสของตัวเอง (`G-01` ในคำศัพท์ · `P-014` ในชุดที่ 1 · `S-` `A-` `B-` ในชุดอื่น)
- ตอบกลับมาในแชตเป็น `G-01 → ...` บรรทัดละคำก็พอ ไม่ต้องเปิดไฟล์ก็ได้ · หรือจะแก้ในไฟล์ตรง ๆ แล้วบอกผมก็ได้

## สิ่งที่ **ไม่ต้อง** ตรวจ

- **ข้อความตอนระบบมีปัญหา** (หน้า 404 · error · เซิร์ฟเวอร์ล่ม · ส่งฟอร์มไม่สำเร็จ) —
  เจ้าของโปรเจกต์ตัดสินใจให้เป็นภาษาอังกฤษทั้งหมดแล้ว ดู [`../lao-copy-review.md`](../lao-copy-review.md) ข้อ 1
- **ชื่อสาขา ชื่อกรรมการ ชื่อผู้สร้างสรรค์ ข้อความในการ์ดหน้าแรก** ที่ทีมพิมพ์เองในหลังบ้าน —
  ของพวกนั้นเป็นข้อมูล ไม่ใช่โค้ด แก้ได้ที่ `/admin` ตลอดเวลา ไม่ต้องรอผม

## ข้อความสองชนิด — แก้คนละที่

1. **อยู่ในโค้ด** (ชุดที่ 1, 3, 4) — ผมแก้ในโค้ดแล้ว deploy ใหม่ จบ
2. **อยู่ในฐานข้อมูล** (ชุดที่ 2) — ต้องแก้ **สองที่**:
   `backend/prisma/seed.ts` (ค่าตั้งต้นของการติดตั้งครั้งใหม่ — ผมทำให้)
   และของจริงบนเว็บที่รันอยู่ ผ่าน `/admin/site` (ทีมกดแก้เอง — ผมส่งข้อความที่แก้แล้วให้ก๊อปวาง)

## หลังจากส่งคำตอบกลับมา

ผมจะ: แทนที่ทุกจุด → รันชุดทดสอบ backend + browser ทั้งหมด →
คอมมิตแยกเป็นชุด ๆ ตามไฟล์ → บอกคำสั่ง deploy

## สิ่งที่ตัดสินใจไปแล้ว — ไม่ต้องถามซ้ำ

- **ชุดคำศัพท์ (`00-glossary.md`) ปิดแล้ว 49/49** — 9 คำแก้ · 40 คำถูกอยู่แล้ว
- **การนับคน** ใช้รูป `ຜູ້ເຂົ້າຊີງ 3 ຄົນ` (คำนาม → ตัวเลข → ลักษณนาม) ไม่ใช่ `3 ຜູ້ເຂົ້າຊີງ`
- **รูป `{ตัวเลข} + ຄົນ / ປີ / ຮູບ / ຂັ້ນ / ຂໍ້ / ທ່ານ / ສາຂາ / ໂລໂກ້ / ໝວດ / ລາຍການ / ຢ່າງ`
  ที่เหลืออีก ~25 จุด ถูกต้องอยู่แล้ว** — เจ้าของโปรเจกต์ยืนยัน ไม่ต้องกลับลำดับ

- **คำเรียก creator ใช้สองคำโดยตั้งใจ** — `ຄຣີເອເຕີ` เวลาพูดกับผู้ใช้ ·
  `ຜູ້ສ້າງສັນເນື້ອຫາ` สำหรับชื่อรางวัลและข้อความทางการ · เหตุผลเต็มอยู่ใน
  [`../seo.md`](../seo.md) ข้อ 4.1
- **เลิกใช้ `ຄອນເທັ້ນ`** ทั้งเว็บ ใช้ `ເນື້ອຫາ` แทน
- **ห้ามเขียน `ຄຣີເອເຕີລາວ`** — เกณฑ์คือภาษาของผลงาน ไม่ใช่สัญชาติของคนทำ
- **คำในตัวโลโก้ (`ນັກສ້າງສັນດິຈິຕອລ`) เป็น final ไม่แก้** — โลโก้เป็นงานออกแบบ
  ไม่ใช่ข้อความของระบบ จึงไม่ต้องตรงกับ glossary
