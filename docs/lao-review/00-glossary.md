# ชุดที่ 0 — คำศัพท์ประจำระบบ (แก้ก่อนอย่างอื่น)

คำในไฟล์นี้คือคำที่ **ถูกใช้ซ้ำทั้งเว็บ** ถ้าคำไหนผิด มันผิดพร้อมกันหลายสิบจุด
แก้ที่นี่ทีเดียวแล้วผมไล่แทนที่ให้ทุกจุดเอง — เร็วกว่าและไม่มีทางตกหล่น

**วิธีกรอก:** เติมช่อง **แก้เป็น**
· ถูกอยู่แล้วใส่ `OK`
· ไม่แน่ใจใส่ `?` แล้วเขียนหมายเหตุต่อท้ายได้
· ถ้าคำนั้นควรใช้คนละคำตามบริบท เขียนแบบนี้: `หน้าเว็บ = xxx / หลังบ้าน = yyy`

ตัวเลข **จุด** คือจำนวนที่พบในโค้ด (นับคำที่มีคำนี้ประกอบอยู่ด้วย จึงเป็นค่าประมาณ)
