# ไฟล์โลโก้ต้นฉบับ

12 ไฟล์ในโฟลเดอร์นี้คือ **ต้นฉบับจากคนออกแบบ** — เก็บไว้อ้างอิงและใช้พิมพ์
**ไม่ได้ถูกเสิร์ฟบนเว็บ** และอยู่นอก build context ของ Docker จึงไม่ทำให้ image ใหญ่ขึ้น

ที่เว็บใช้จริงคือไฟล์ใน `frontend/public/brand/` กับ `frontend/src/app/` ซึ่ง
**เรนเดอร์มาจากไฟล์ในโฟลเดอร์นี้** (ดูวิธีท้ายไฟล์)

## ไฟล์ต้นฉบับ 12 ตัว

| ชุด | Black | White | Full Color |
|---|---|---|---|
| **BrandMark** (โลโก้เดี่ยว) | 37K · **เวกเตอร์แท้** | 37K · **เวกเตอร์แท้** | 7.9 MB |
| **Horizontal** (มาร์ก + ชื่อ) | 159K | 46K | 7.9 MB |
| **Main** (วางซ้อนแนวตั้ง) | 152K | 43K | 7.9 MB |
| **Wordmark** (ชื่ออย่างเดียว) | 88K | 6K | 8.2 MB |

## สิ่งที่ต้องรู้ก่อนใช้ไฟล์พวกนี้

1. **ไฟล์ Full Color ไม่ใช่เวกเตอร์** — พื้นผิวฟอยล์คือ PNG ขนาด 5600×5600 (7.95 MB)
   ที่ถูก `<use>` ซ้ำหลายครั้งโดย clip เป็นรูปมาร์กกับตัวอักษร · และเป็น **ไฟล์เดียวกัน
   ฝังซ้ำใน 4 ไฟล์** (md5 ตรงกัน) = ~32 MB ของโฟลเดอร์นี้มาจากพื้นผิวชิ้นเดียว
2. **Horizontal / Main / Wordmark แบบ Black ก็ไม่ใช่เวกเตอร์** — เป็น PNG ห่อใน `.svg`
   (1966×608 · 1065×1038 · 1632×611) · มีแต่ **BrandMark** ที่เป็น path จริง
3. **ไฟล์ White และ Full Color มี `<text>` ที่ยังไม่แปลงเป็นเส้น** อ้างอิงฟอนต์
   `Montserrat-Medium` และ `NotoSansLao-Regular` · SVG ที่แสดงผ่าน `<img>` **ใช้ฟอนต์
   ของหน้าเว็บไม่ได้** (เป็นเอกสารแยก) เครื่องที่ไม่มีฟอนต์จะเรนเดอร์ผิด →
   **ห้ามเอา .svg พวกนี้ขึ้นหน้าเว็บโดยตรง** ให้ใช้ไฟล์ที่เรนเดอร์แล้วเท่านั้น
4. **Horizontal Black ไม่มีบรรทัดภาษาลาว** แต่ White กับ Full Color มี — สองแบบไม่ตรงกัน
5. **บรรทัดลาวในโลโก้เขียนว่า `ລາງວັນນັກສ້າງສັນດິຈິຕອລແຫ່ງປີ`** ซึ่งใช้คำที่สาม
   (`ນັກສ້າງສັນດິຈິຕອລ`) ไม่ตรงกับคำที่เว็บใช้ (`ຄຣີເອເຕີ` / `ຜູ້ສ້າງສັນເນື້ອຫາ` — ดู
   [`../../seo.md`](../../seo.md) ข้อ 4.1) · คำนี้อยู่ในงานออกแบบ แก้ได้เฉพาะคนทำโลโก้

## ที่จะขอจากคนออกแบบ

1. ไฟล์ **White ทุกตัวแบบแปลงตัวอักษรเป็นเส้นแล้ว** (outline / convert text to path)
   → จะได้เวกเตอร์แท้ทั้งชุด ไฟล์เล็ก คมทุกขนาด ไม่พึ่งฟอนต์
2. **โลโก้แบบสีที่เป็นเวกเตอร์จริง** (ฟอยล์เป็น gradient ไม่ใช่รูปถ่าย) ถ้าทำได้ ·
   ถ้าไม่ได้ ขอพื้นผิวไม่เกิน 1500px ก็พอสำหรับเว็บ
3. **มาร์กแบบเรียบง่ายสำหรับ favicon** — มาร์กตอนนี้เป็นลายเส้นบางล้วน ที่ 16–20 px
   (ขนาดจริงในแท็บเบราว์เซอร์) มันรวมกันเป็นก้อนอ่านไม่ออก · ขอแบบที่ตัดรายละเอียด
   ออกให้เหลือรูปทรงหลัก
4. บรรทัดลาวใน Horizontal Black ให้ตรงกับ White/Full Color (หรือยืนยันว่าตั้งใจไม่ใส่)
