02

หน้าแรก — brand hub

/

Evergreen ทั้งหน้า มีเพียง 2 จุดที่อัปเดตอัตโนมัติ: การ์ดสถานะปีปัจจุบัน (2) และไฮไลต์ผู้ชนะ (4) — ไม่มี section สปอนเซอร์ ไม่มีธีมรายปี

  1. 1Nav กลาง — โลโก้ + ปีล่าสุด + ผู้ชนะ + เกี่ยวกับ + CTA ส่งรายชื่อ (โผล่เฉพาะเฟสเปิดรับ) ไม่มีเมนู Voting/Ticket
  2. 2Hero + การ์ดทางเข้า 2 ใบ — ใบซ้ายคือจุดเดียวของงานปีปัจจุบันบนหน้าแรก มีลิงก์รองซื้อบัตร/โหวตเมื่อปีนั้นกรอก URL ไว้
  3. 3Muan Awards คืออะไร — ย่อจาก /about
  4. 4ไฮไลต์ผู้ชนะปีล่าสุด — เฉพาะสาขาเด่น (isFeatured) สลับปีเองเมื่อประกาศผลปีใหม่
  5. 5ตัวเลขสะสม — คำนวณจากข้อมูลจริง
  6. 6Quick links
  7. 7Footer — social + ติดต่อ

Phase

  1. 1Hero ของปี — key visual รายปี + CTA สูงสุด 3 ปุ่ม (ตามเฟส / ซื้อบัตร / โหวต) อัตลักษณ์ปีจำกัดอยู่ในกรอบนี้

  4. 4ตารางสรุปผู้ชนะ — เฉพาะเฟสประกาศผล มือถือยุบเป็น list
  5. 5กิจกรรมในงาน
  6. 6คณะกรรมการ — ประธานขึ้นก่อน
  7. 7สปอนเซอร์ของปี — จัดกลุ่มตาม tier

สิ่งที่ยังต้องตัดสินใจ

ก่อนเริ่ม scaffold โปรเจกต์

สาขาเด่น (isFeatured) ของแต่ละปีmockup สมมติไว้ 4 สาขา — ต้องเลือกจริง 3–6 สาขา (คำถามเปิดข้อ 7 ใน PRD)
จำนวนสาขาต่อปีmockup ใช้ 18 สาขา ถ้าเกิน 25 สาขา accordion จะยาวเกินไป อาจต้องจัดกลุ่มหมวดเพิ่ม (คำถามเปิดข้อ 4)
รูปครีเอเตอร์ทุกการ์ดในหน้านี้เป็นช่อง avatar เปล่า — ต้องได้ข้อสรุปเรื่องสิทธิ์ใช้รูป (คำถามเปิดข้อ 5)
ไฟล์เวกเตอร์ + faviconยังใช้ PNG อยู่ ตกลงกันแล้วว่าเริ่มได้เลยแล้วสลับ SVG ทีหลัง
Copy ภาษาลาวข้อความในหน้านี้เป็นตัวอย่างจากทีมพัฒนา ต้องให้ทีม content ตรวจและเขียนจริง
